# Formula U Racing website

A responsive, dependency-free static site for Formula U Racing at the University of Utah.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server. For example:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

Upload the complete folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel, or a university web host). There is no build step and no package installation required.

## Contents

- `index.html` - page content and supplied official links
- `styles.css` - responsive visual design
- `script.js` - mobile navigation, scroll behavior, and restrained reveal motion
- `assets/` - supplied Formula U logo, team/car photos, and sponsorship packet

## Before publishing

1. Confirm the Discord invite. This site uses the invite supplied for this project: `https://discord.gg/42Su3WfqSG`.
2. Ask the team to review current contacts, vehicle specifications, and sponsorship language.
3. Get University approval before changing University marks, adding sponsor logos, or promising sponsor benefits. The packet's sponsorship language intentionally remains conditional.

## Updating content

All copy is in `index.html`. Search for the section heading you want to update. Keep vehicle data and sponsor terms aligned with the most recent approved sponsorship packet.
